# Code of conduct

Be kind and keep it practical.

- Treat everyone with respect, whatever their experience level. Many people here are new to modding.
- Criticize code and ideas, not people.
- No harassment, insults, or posting other people's private information.
- Assume good faith, and say plainly when something is unclear.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, contact the maintainers through GitHub.
